# Date Pages — home page

The public home page for a personal-dating-website and merchandise brand.
One static HTML file plus images. No build step, no dependencies.

**Live:** https://katedoes.github.io/date-pages-site/

## Run it locally
```
python3 -m http.server 4321
```
Then open http://localhost:4321.
